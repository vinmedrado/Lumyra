# Lumyra — Demo Mode

O modo demo foi criado para apresentações rápidas em GitHub, LinkedIn, vídeo demo, recrutadores e clientes.

## Como popular dados

```bash
python scripts/seed_demo_data.py
```

## Frontend

A landing page possui CTA `Explore Demo`. A tela de login também possui botões para:

- Demo Assessoria
- Demo Noivos
- Demo Convidado

Esses atalhos não gravam dados reais e foram pensados para portfólio.
